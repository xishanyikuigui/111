🔍 搜索绩效 (SQP) 核心字段说明

• 搜索量 / 您的订单 / 点击 / 曝光

品牌分析后台(Search Query Performance)的官方核心指标，反映产品在特定买家搜索行为下的自然和广告累积流量基本盘。

• 购买占比 / 点击占比 / 曝光占比

代表该检索词下，本 ASIN 的贡献量占大盘该词总流量之比例，折射出您在各流量漏斗层级上的市占控制实力。

• 点击/曝光占比比值 (Ci)

等于（本词点击占比 ÷ 曝光占比）。若此值 > 1.1 说明产品具备强健的曝光点击引导力，通常得益于主图创意、价格及Review评级的视觉溢价。

• 购买/点击占比比值 (Bi)

等于（本词购买占比 ÷ 点击占比）。若此值 > 1.15 说明到达详情页面的买家购买决策速度极高，详情页卖点承接极为精准。

📢 广告词分析 (Ads) 核心指标说明

• 广告投入占比 (Ad Spend Share)

等于（本词广告消耗 ÷ 总广告消耗）。用以监测并排查哪些词在悄然侵吞、蚕食您的预算，防止无转化词形成财务吞噬黑洞。

• 直接订单率 (Direct Order Ratio)

直接订单/总广告订单。体现点击24小时内在同 ASIN 下支付的商品量。此比例极高（≥70%）说明推款精准度完美，是打爆大盘排名的最强催化剂。

• CVR / CPA / CTR

经典的搜广推漏斗诊断指标：本工作台采用综合复合咬合算法，判定流量在点击引导率、CPA获客财务效益及转化率（CVR）上的综合平衡并生成出价推荐。

策略大盘自动交叉打标规则 (核心双融固化逻辑)

SQP 详情承接力
  • 🟢 承接力碾压：转化效率比值 ≥ 1.15 且产品最终转化率强于大盘同期。
  • 🔴 价格/价值错配：转化比值 < 0.85 且您的溢价偏高，导致购买受阻。
  • ⚪ 承接力均衡：各项指标偏失在常规界限内震荡。
Ads 归因属性
  • 🎯 爆款推类型：直接订单占比 ≥ 70%，代表广告完美打中核心心智，应主力卡位投算。
  • 🔄 混合转化型：直接订单占比介于 30% ~ 70%，在强相关与边缘属性中取得妥协。
  • 🔗 矩阵引流型：直接订单占比 < 30%，产生跨ASIN的关联裂变引流。
Cross 预算效率
  • 🟢 高效收割：订单占比极高（>10%）且广告消耗预算极低（≤10%），极其暴利。
  • 🟡 规模支撑：消耗占比与订单转化对等偏高，系构成爆款销量的绝对底支撑。
  • 🔴 预算黑洞：曝光巨大，消耗极多（>10%）但实际转化很少（≤10%）。
Cross 流量渠道关系
  • 🚀 增效型：广告 CVR 胜过大盘 1.2 倍但自然占比落后，具有贵重的荒漠引爆增势价值。
  • 🛡️ 防守型：自然卡位极其稳定，广告极少投算，适合使用极低 Bid 精细维卡防守。
  • ⚠️ 蚕食型：广告花费不菲但其CVR明显偏低，可能正以亏本卡位侵蚀既得自然购买单量。
  • 🔥 消耗型：双渠道转化偏微，仅依靠巨量广告预算长效空转。
